# bunker-game
Bunker Survival Simulator — текстовая стратегия в стиле CRT-терминала Fallout.  Ты — Смотритель бункера. Управляй ресурсами (еда, вода, фильтры) и руководи группой из 12 профессий (от врача до SEO-специалиста). Назначай задачи, отправляй вылазки в Пустошь и принимай решения в ежедневных событиях.  Продержись как можно дольше!
